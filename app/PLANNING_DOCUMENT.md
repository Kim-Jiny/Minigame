# DUO 기획서

## 1. 프로젝트 개요

### 1.1 앱 정보
| 항목 | 내용 |
|------|------|
| **앱 이름** | DUO |
| **장르** | 캐주얼 멀티플레이어 미니게임 |
| **플랫폼** | iOS, Android |
| **타겟 연령** | 전 연령 (14세 이상 권장) |
| **버전** | 1.0.0 |

### 1.2 핵심 컨셉
> **"친구와 함께하는 1:1 두뇌 대결"**

DUO는 간단하지만 중독성 있는 미니게임을 친구 또는 랜덤 상대와 실시간으로 즐길 수 있는 캐주얼 게임 앱입니다.

### 1.3 차별화 포인트
- **실시간 1:1 대전**: 소켓 기반 실시간 매칭 및 게임 진행
- **다양한 게임**: 8종의 미니게임 제공
- **소셜 기능**: 친구 추가, 친구 초대, 채팅
- **경쟁 시스템**: 랭크전, 리더보드, 티어 시스템
- **커스터마이징**: 프레임, 칭호, 테마, 아바타

## 2. 게임 목록

### 2.1 전략 게임
| 게임 | 설명 | 특징 |
|------|------|------|
| **틱택토** | 3x3 오목 | 클래식 모드, 하드코어 모드 |
| **무한 틱택토** | 4번째 수부터 첫 수 제거 | 무한 전략, 하드코어 모드 |
| **오목** | 15x15 오목 | 하드코어 모드 |

| 게임 | 설명 | 특징 |
|------|------|------|
| **반응속도** | 신호에 빠르게 반응 | 5라운드 대결 |
| **스피드탭** | 빠르게 탭하기 | 10초간 탭 횟수 |

### 2.3 인지 게임
| 게임 | 설명 | 특징 |
|------|------|------|
| **가위바위보** | 가위바위보 대결 | 5판 3선승 |

### 2.4 게임 모드
- **일반 모드**: 기본 룰, 턴당 15초
- **하드코어 모드**: 턴당 5초, 더 높은 보상

## 3. 핵심 기능

### 3.1 매칭 시스템
```
[매칭 요청] → [대기열 진입] → [상대 매칭] → [게임 시작]
```
- 랜덤 매칭: 전 세계 유저와 대전
- 친구 초대: 특정 친구에게 게임 초대

### 3.2 랭크 시스템
| 티어 | ELO 범위 | 아이콘 |
|------|----------|--------|
| Bronze | 0 - 999 | 🥉 |
| Silver | 1000 - 1499 | 🥈 |
| Gold | 1500 - 1999 | 🥇 |
| Platinum | 2000 - 2499 | 💎 |
| Diamond | 2500 - 2999 | 💠 |
| Master | 3000+ | 👑 |

### 3.3 친구 시스템
- 친구 코드로 친구 추가
- 친구 목록 및 온라인 상태 확인
- 1:1 채팅
- 게임 초대

### 3.4 상점 시스템
| 카테고리 | 아이템 예시 |
|----------|------------|
| 프레임 | 기본, 골드, 레인보우, 불꽃 |
| 칭호 | 뉴비, 승부사, 전설, 챔피언 |
| 테마 | 기본, 다크, 오션, 선셋 |
| 아바타 | 기본, 동물, 캐릭터 |
| 티켓 | 닉네임 변경권 |

## 5. 데이터 모델

### 5.1 사용자 (Users)
```
- id: 고유 식별자
- email: 이메일
- nickname: 닉네임
- provider: 로그인 방식 (google/apple)
- coins: 보유 코인
- friend_code: 친구 코드
- created_at: 가입일
```

### 5.2 게임 통계 (Game Stats)
```
- user_id: 사용자 ID
- game_type: 게임 종류
- wins: 승리 수
- losses: 패배 수
- draws: 무승부 수
```

### 5.3 랭크 정보 (Ranked Stats)
```
- user_id: 사용자 ID
- elo: ELO 점수
- tier: 티어
- wins: 랭크 승리
- losses: 랭크 패배
```
