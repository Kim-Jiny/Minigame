자주 묻는 질문

회원가입이나 로그인이 필요한가요?

아니요. 사자툰은 가입·로그인 없이 바로 사용할 수 있습니다.

학습 진도(완료·북마크)가 사라졌어요.

학습 진도는 사용 중인 기기를 기준으로 저장됩니다. 앱을 삭제하거나 기기를 바꾸면 진도가 초기화될 수 있습니다.

새로운 사자성어는 언제 추가되나요?

콘텐츠는 꾸준히 추가·업데이트됩니다. 앱을 켜면 최신 내용으로 자동 갱신됩니다.

만화 이미지가 안 보이거나 느려요.

네트워크 상태를 확인하고, 모아보기 화면을 아래로 당겨 새로고침해 보세요. 계속 문제가 있으면 위 이메일로 알려주세요.

내용 오류(뜻·한자·퀴즈)를 발견했어요.

정확한 콘텐츠를 위해 노력하고 있습니다. 해당 사자성어와 내용을 위 이메일로 보내주시면 검토 후 반영하겠습니다.

내 데이터를 삭제하고 싶어요.

앱을 삭제하면 기기에 저장된 데이터가 함께 삭제됩니다. 서버에 저장된 익명 데이터 삭제를 원하시면 위 이메일로 요청해 주세요.
