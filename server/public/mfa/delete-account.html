계정 삭제 안내

앱 설치 여부와 무관하게 확인할 수 있는 계정·데이터 삭제 방법 안내

"성인의 수학"은 로그인(Google·Apple·Kakao)이 선택 사항이며, 로그인 계정은 앱 안에서 언제든 직접 삭제할 수 있습니다. 아래는 삭제 방법과 삭제되는 범위에 대한 안내입니다.

1. 앱 안에서 삭제하기

  1. 앱 실행 → 설정 → 계정
  2. 회원탈퇴 메뉴 선택
  3. 안내 문구 확인 후 탈퇴 확정

탈퇴는 즉시 처리되며 별도 대기 기간이 없습니다.

2. 삭제되는 항목

  • 계정 정보(소셜 로그인 식별자, 이메일, 닉네임)
  • 클라우드에 저장된 학습기록(여러 기기 동기화용으로 서버에 있던 진도·통계)
  • 계정과 구매 내역의 연결 정보(힌트쿠폰 잔액 등 계정 귀속 데이터)

3. 삭제되지 않거나, 별도로 보관되는 항목

  • 이 기기에 로컬로 남아있는 학습기록은 탈퇴와 무관하게 유지됩니다(게스트로 계속 사용 가능). 완전히 지우려면 기기에서 앱을 삭제하세요.
  • 인앱결제 기록은 전자상거래 등에서의 소비자보호에 관한 법률 등 관계 법령이 정하는 기간 동안 대금결제·재화공급에 관한 기록으로 보관될 수 있습니다(일반적으로 5년). 이 경우 특정 계정과의 연결은 즉시 해제되고 거래 기록만 보관됩니다.

자세한 내용은 개인정보처리방침을 참고하세요.

4. 앱을 설치하지 않고 삭제를 요청하려면

탈퇴하려는 계정의 가입 이메일(또는 닉네임)과 함께 아래 연락처로 요청해 주세요. 본인 확인 후 영업일 기준 5일 이내에 처리합니다.
